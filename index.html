Route Overlay Generator

Build a precision flying overlay in your browser using calibrated map presets.

1. Map & Flight Parameters

Choose a calibrated map preset. All processing stays in your browser.

2. Timing & Markers

Adjust markers without scrolling; units auto-convert for speed inputs (kt, mph, km/h).

3. Overlay Styling

Values are base sizes on the VFR chart; they auto-scale for other presets.

4. Waypoints

PHOTO_name,latitude,longitude rows define DOF025 photo targets and are excluded from route geometry.

5. Photos & Tasks

Private by design: photos, EXIF metadata, analysis, and generated files stay in this browser tab. Bundled-map mode makes no third-party map request. Choosing OSM tiles, finding OSM targets, or importing GURS imagery sends only the relevant displayed area, bounded route corridor, or selected coordinates. OSM discovery tries maps.mail.ru first and contacts overpass.private.coffee or overpass-api.de only if the preceding service fails.

The historical example is about 49 MB and loads only when requested.
